## ADDED Requirements

### Requirement: Docs header links to GitHub repository
The documentation site SHALL display a clickable GitHub icon in the header that navigates to `https://github.com/wooters/pyminidsp`.

#### Scenario: User clicks GitHub icon
- **WHEN** a user visits any page of the Sphinx documentation
- **THEN** a GitHub icon SHALL be visible in the header navigation bar, linking to `https://github.com/wooters/pyminidsp`
